# EXIN Teams Lite

Lightweight guild team and roster management addon.

## Installation

1. Download the `EXINTeamsLite-<version>.zip` build artifact.
2. Extract the `EXINTeamsLite` folder.
3. Place that folder in your World of Warcraft `_retail_/Interface/AddOns/` directory (or the equivalent AddOns directory used by your game client).
4. Enable **EXIN Teams Lite** from the AddOns list.
5. Log in with a guild character and type `/exin`.

## Development status

This is a development build. It has not yet been verified in the live game client or tested with multiple guild members. Interface compatibility and addon-message behavior must be confirmed in-game.

## Distribution scope

The installation archive contains only the `EXINTeamsLite/` directory. It does not include the separate `ForeverTeams/` Full edition source.
